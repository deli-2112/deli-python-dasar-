# Praktikum Python Dasar (SantriKoding)

Repository ini berisi dokumentasi kode program, bukti tangkapan layar eksekusi, serta riwayat pembelajaran bertahap untuk modul **Python Dasar** dari SantriKoding (Bab #1 hingga Bab #19).

## Struktur Direktori
- `bab1.py` – `bab19.py` : Implementasi kode praktik untuk setiap bab tutorial.
- `modul_matematika.py` & `paket_sekolah/` : Modul dan paket pendukung untuk Bab #18 dan Bab #19.
- `screenshots/` : Kumpulan tangkapan layar hasil eksekusi setiap program.
- `requirements.txt` : Daftar dependensi lingkungan virtual proyek.

## Rangkuman Materi yang Dipelajari
1. **Dasar & Sintaks (Bab #1 – #5):** Instalasi Python, struktur dasar, indentasi, tipe data dasar, variabel, dan konstanta.
2. **Logika & Struktur Data (Bab #6 – #10):** Operator, percabangan (`if-elif-else`), perulangan (`for`, `while`), fungsi, `list`, `tuple`, `set`, dan `dictionary`.
3. **Pemrograman Berorientasi Objek / OOP (Bab #11 – #15):** Kelas & objek, enkapsulasi, pewarisan (*inheritance*), polimorfisme, dan abstraksi.
4. **Lanjutan & Modularitas (Bab #16 – #19):** Penanganan pengecualian (`try-except`), operasi baca/tulis file, pembuatan modul, dan struktur *package*.
